# Core-Based Statistical Areas 2018 rural definition

County-level rural classification based on the 2018 OMB mid-decade
delineation update.

## Usage

``` r
cbsa_2018
```

## Format

A tibble with 5 variables:

- geoid:

  string County GEOID code

- name:

  string Name of the rural definition

- year:

  dbl Year the definition was released

- rural_def:

  string Detailed rural classification: Metro, Micro, or Non-CBSA

- is_rural:

  string Value of either Rural or Nonrural
