# Core-Based Statistical Areas 2020 rural definition

County-level rural classification

## Usage

``` r
cbsa_2020
```

## Format

A tibble with 3234 rows and 5 variables:

- geoid:

  string County GEOID code

- name:

  string Name of the rural definition

- year:

  dbl Year the definition was released

- rural_def:

  string Detailed rural classification if relevant

- is_rural:

  string Value of either Rural or Nonrural
